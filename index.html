저장된 전술

전술 저장·수정은 관리자만 가능해요. 위 버튼을 누르면 로그인할 수 있어요.
사용법 — 원(우리 팀) · 사각형(상대 팀) · 오각형(교체 선수) · 공을 눌러서 끌면 그대로 따라 움직여요. 토큰 가운데를 끌면 위치가 이동하고, 토큰 테두리 쪽을 끌면 선수가 바라보는 방향이 바뀌어요 — 안에 적힌 번호/이름이 회전된 정도가 바로 그 방향이에요(별도 화살표 표시는 없어요). 교체 선수는 "교체 선수 명단"에서 인원을 추가해야 코트 왼쪽에 나타나요 (기본은 0명). 더블클릭하면 이름/색상을 편집할 수 있어요(관리자만 가능, 공은 예외로 누구나 더블클릭하면 가운데로 되돌아갑니다). 코트는 항상 화면 너비에 꽉 차게 표시돼요 — 가로 화면처럼 세로 공간이 부족하면 코트 영역 안에서 위아래로 스크롤해서 나머지를 볼 수 있어요. 왼쪽 위 ＋/－ 버튼이나 Ctrl(트랙패드 핀치)+스크롤로 추가 확대·축소도 가능해요. 로테이션/상황을 바꾸면 우리 팀은 해당 템플릿 배치로 돌아갑니다.
배구 지도용 전술 시각화 도구 · 실제 경기 규칙 및 소속 리그 규정과 다를 수 있으며, 코칭 설명을 돕기 위한 예시 대형입니다.

이용방법

🏐 시작하기

  • 처음 들어오면 팀 선택 화면이 나와요. 원하는 팀을 눌러 들어가세요.
  • 팀에 자물쇠(🔒) 표시가 있으면 비밀번호가 필요해요 (기본 비밀번호: 1234).
  • 관리자로 로그인하면 비밀번호 없이 모든 팀에 들어갈 수 있고, 팀 추가/이름변경/삭제·비밀번호 설정도 할 수 있어요 (관리자 기본 비밀번호: coach1234).

🧭 코트 화면 조작

  • 6인제 / 9인제 버튼으로 방식을 바꿀 수 있어요. 9인제는 로테이션이 없어요.
  • 로테이션, 상황(서브·리시브·공격·블로킹·수비) 버튼을 누르면 정해진 기본 대형으로 이동해요.
  • 코트 왼쪽 위 ＋ / － 버튼이나 Ctrl+스크롤(트랙패드 핀치)로 확대·축소할 수 있어요.
  • ⤢ 가로로 보기 — 코트를 90도 돌려서 넓은 화면(PC)에 맞게 볼 수 있어요.
  • ⛶ 전체화면 — 코트만 화면 가득 크게 볼 수 있어요 (Esc로 나가기).
  • 코트는 항상 화면 너비에 꽉 차게 나오고, 세로 공간이 부족하면 코트 안에서 스크롤해서 나머지를 봐요.

🙋 선수 조작 (누구나 가능)

  • 원 = 우리 팀, 사각형 = 상대 팀, 오각형 = 교체 선수, 흰 공 모양 = 공
  • 토큰 가운데를 끌면 이동, 테두리 쪽을 끌면 회전해요 — 안에 적힌 번호/이름이 돌아간 방향이 그 선수가 보고 있는 방향이에요.
  • 상대 팀 위치를 먼저 배치해두고, 그에 맞춰 우리 팀 위치를 조정해보는 용도로 쓸 수 있어요.
  • 교체 선수 명단에서 ＋/－ 로 인원(0~10명)을 조절해요. 0명이면 화면에 안 보여요.
  • 각 팀/공 옆의 "위치 초기화" 버튼으로 원래 자리로 되돌릴 수 있어요.

🔒 관리자 전용 기능

  • 선수·상대팀·교체선수 토큰을 더블클릭하면 이름과 색상을 바꿀 수 있어요.
  • 전술 저장 — 원하는 대형을 만든 뒤 "+ 현재 배치를 새 전술로 저장"으로 이름 붙여 저장. 위치와 방향, 교체 인원까지 함께 저장돼요.
  • 저장된 전술은 누구나 클릭해서 불러올 수 있지만, 이름 변경(✎)·삭제(×)·새로 저장하는 건 관리자만 가능해요.
  • 비밀번호 변경 — 관리자 비밀번호를 원하는 값으로 바꿀 수 있어요.
  • Firebase 연결 — 연결하면 다른 기기·다른 브라우저에서도 같은 데이터를 볼 수 있어요.

💾 데이터 저장 안내

  • 화면 위쪽의 작은 점 표시로 지금 데이터가 어떻게 저장되는지 알 수 있어요.
  • ● Firebase 연결됨 / Claude 공유 저장소 — 누구나 같은 데이터를 봐요.
  • ● 이 브라우저에만 저장 — 다른 기기와 공유되지 않아요.
